```

stations/live?city_id=            ← band_thresholds ficam aqui
stations/list?city_id=
city-site/stations?city_id=
city-site/cota-advisory?city_id=
station-history?station_id=&start=&end=&fields=level|rain&resolution=hourly|raw
dams?city_id=      shelters?city_id=
cities/<ibge>      cities?uf=SC   state-bulletins?uf=SC
```
